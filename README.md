- `masem.html`
- `styles.css`

## Privacy approach
The site intentionally uses generalized, non-confidential descriptions.
Do not upload raw client data, private emails, internal decks, or restricted metrics.

## Publish with GitHub Pages
1. Create a repository, e.g. `research-portfolio`
2. Upload all files in this folder
3. Go to Settings → Pages
4. Deploy from `main` branch, root folder
5. GitHub will provide the public URL

## Before publishing
- Add LinkedIn and GitHub profile URLs
- Optionally add a resume PDF
- Review project wording one final time for client confidentiality
